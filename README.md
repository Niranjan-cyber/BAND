# dark-factory-pocketful

Hackathon template repo: infrastructure and process only, no product logic.

## Start of an event
1. Create a new repo from this template.
2. Fill `docs/brief.md`; write `docs/demo-script.md`.
3. Push; confirm the pipeline deploys hello-world and the smoke test passes on the public URL.
4. Follow the build-hackathon skill from phase 2 (walking skeleton).

## Layout
See `AGENTS.md` for rules, `RUNBOOK.md` for commands, `LEARNING.md` for the running log, `CREDITS.md` for
declarations.
